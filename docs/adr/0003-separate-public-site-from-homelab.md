# 0003. 公開サイトを自宅ラボに依存させない

- 状態: Accepted
- 日付: 2026-11-20

## 背景

自宅の Proxmox は停電・回線障害・IP 変動・メンテナンスで止まる。採用担当などが閲覧したタイミングでサイトが落ちていると逆効果になる。

## 決定

- ポートフォリオ本体は Cloudflare Workers に置き、自宅ラボが止まっても表示できるようにする
- 自宅ラボはデモや検証の場として使い、Cloudflare Tunnel 経由で個別に公開する
- 自宅ラボの状態をサイトに出す場合は、外部（Oracle Cloud / Workers）で集計・キャッシュしたものを表示し、取得できないときはフォールバック表示にする

## 結果・トレードオフ

- 本体の可用性が自宅環境に左右されない
- 自宅ラボ上のデモは落ちることがある前提になる。ステータスページで状態を明示する

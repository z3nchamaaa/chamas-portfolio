# 0004. インバウンドのポートを開けない

- 状態: Accepted
- 日付: 2026-11-20

## 背景

自宅回線とクラウド VM の両方を外部に公開するため、攻撃面を最小にしたい。

## 決定

- 公開は Cloudflare Tunnel（cloudflared からの外向き接続）で行い、ルーターのポート開放はしない
- 管理用のアクセスは Tailscale 経由に限定する
- Oracle Cloud の VM の SSH は、Tailscale 導入前の初回セットアップ時だけ接続元 IP を絞って開ける

## 結果・トレードオフ

- 自宅のグローバル IP を公開せずに済む
- Cloudflare と Tailscale が止まると外部からアクセスできない（その場合は自宅内から作業する）
